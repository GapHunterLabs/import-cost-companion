# Privacy Policy — Import Cost Companion

**Effective date:** 2026-08-14

Import Cost Companion is a Gap Hunter Labs plugin for IntelliJ
Platform IDEs. This policy is short because the plugin's design makes
it short: there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** Import Cost Companion does not collect, store, transmit,
or sell any data — no source code, no file contents, no usage
analytics, no telemetry, no crash reports, no personally identifiable
information.

## Network access

**None.** Import Cost Companion makes zero network calls during normal
operation. Every check it performs runs entirely in-process, reading
files already on your own disk (`node_modules`). Nothing you write,
open, or edit is ever sent anywhere.

## Third parties

None. Import Cost Companion has no third-party SDKs, no analytics
libraries, no ad networks, no external dependencies that phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
